# Triage labels

Mapeamento dos papéis de triagem para as labels do projeto.

| Papel | Label | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Precisa de avaliação |
| needs-info | needs-info | Aguarda mais informações |
| ready-for-agent | ready-for-agent | Especificado e pronto para um agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será implementado |

Quando uma Skill mencionar um papel de triagem,
usar a label correspondente desta tabela.
